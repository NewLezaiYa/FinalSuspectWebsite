01自动更新

Final Suspect 已于游戏内内置更新检查，每次启动将自动检查更新。

在有更新时会要求您更新，否则您无法继续游玩。

有关更新的详细信息，请查看版本更新日志。

两个渠道的检查逻辑不同

Release 版本与 OpenBeta 版本的更新检查逻辑不同： Release 不会要求您更新到 OpenBeta 版本，而 OpenBeta 则不会进行更新检查。

02何时需要手动更新

优先选择自动更新

如非必要，我们建议您优先选择自动更新。

只有在遇上更新检查失败或下载出现问题时，才需要按下面的四步手动更新。

03手动更新步骤

访问 GitHub Releases，下载最新版本的 dll 文件。

打开 Among Us 根目录，再继续打开 BepInEx\plugins 文件夹。

Among Us\BepInEx\plugins
插件目录 
Among Us\BepInEx\plugins

将下载的 dll 文件替换掉原有的 dll 文件。

至此，更新结束。
