快捷键

开始 10 组按键 更新于

仅适用于模组端的快捷键。前两组为通用操作，其余为房主专用控制。 键盘表按「按键 → 作用」排列，方便横向扫读。

通用快捷键8 组
房主专用2 组
生效端模组端（非原版）
组合键写法同时按下

01模组端快捷键

以下快捷键在 Final Suspect 模组端全局生效。

F11
更改分辨率
F4
更改全屏
F5+T
重新加载自定义翻译文件
F5+X
导出自定义翻译文件
F1+左Ctrl/右Ctrl
输出日志
F2+左Ctrl/右Ctrl
游戏中输出日志
F10
打开游戏目录
TAB
显示 / 隐藏主页 UI
关于输出日志

按 F1 输出的日志会落在模组专用目录， 具体位置与手动查找方式见 导出日志。

02房主专用快捷键

生效条件

该组快捷键仅限自己是房主，且处于 FinalSuspect 模组端时生效。

左Shift/右Shift
将大厅房间倒计时修改为 0 秒
C
重置房间倒计时

03与其他功能的搭配

人满自动开始游戏 输出日志功能
房主小技巧

配合「人满自动开始游戏」使用：倒计时由模组自动触发时，仍可用 C 重置、用 Shift 直接归零。
